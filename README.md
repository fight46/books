> 只收录亲自完整读过、且确认有重读价值的书。

> 好书不是读一遍就够的。不同年纪、不同境遇再翻开，总会读出新的答案。

## 认知思维
- **《思考，快与慢》** - 丹尼尔·卡尼曼
  关于人类思维两套运行系统的经典。每次重读都能对照出自己近期犯过的思维误区。

- **《原则》** - 瑞·达利欧
  不是成功学鸡汤，是一套可落地的决策与行事框架。不同人生阶段读，总能对应到当下的困境。

## 人文历史
- **《万历十五年》** - 黄仁宇
  以小见大的历史写法，跳出编年叙事，读懂制度与人性如何共同塑造历史走向。

## 文学经典
- **《活着》** - 余华
  每次读都能对“苦难”和“活着本身”有新的理解。心浮气躁的时候翻开，人会慢慢沉下来。

## 心理成长
- **《被讨厌的勇气》** - 岸见一郎 / 古贺史健
  阿德勒心理学的入门佳作。迷茫、内耗时重读，能帮你把目光从“别人怎么看”拉回“自己怎么做”。

## 工具方法
- **《金字塔原理》** - 芭芭拉·明托
  思考、表达、写作的底层逻辑框架。常读常新，每次复盘都能修正自己的表达习惯。

## 选书标准
1.  本人完整阅读过至少一遍，核心书目反复读过多次
2.  内容有厚度，非快餐式读物，经得起时间和重复阅读
3.  能提供新的视角、思维方式或稳定的情绪价值，而非单纯堆砌信息
